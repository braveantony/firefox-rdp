# Firefox 遠端桌面使用手冊

適用映像檔：`ghcr.io/braveantony/rdp-firefox:3.7-share`（`:3.6-share` 的 `localhost:2210` 要另外設定 22100 埠，且多帳號時無法登入；`:3.5-share` 另外沒有桌面內的中文輸入法，中文只能貼上；`:3.4-share` 另外只有單一帳號）。安裝方式請見 [install.md](install.md)。

用 Windows 內建的「遠端桌面連線」登入後，畫面上只有一個全螢幕的 Firefox。多人可以同時連線，各自有獨立的桌面；需要時也可以把自己的桌面分享給別人看或一起操作。

## 1. 連線與登入

| 項目 | 值 |
| --- | --- |
| 電腦 | `192.168.11.64` |
| 帳號 | 管理者發給你的帳號（單一帳號的環境通常是 `bigred`） |
| 密碼 | 管理者發給你的密碼 |

1. 按 `Win+R`，輸入 `mstsc`，按 Enter，開啟「遠端桌面連線」。
2. 電腦欄位填 `192.168.11.64`，按「連線」。
3. 出現憑證警告（「無法驗證此遠端電腦的身分識別」）時，按「是」。每個 Pod 使用自己產生的憑證，這是正常的。
4. 畫面會出現 xrdp 的登入畫面，有三個欄位：

   | 欄位 | 填入 |
   | --- | --- |
   | Session | 保持 `Xorg`（預設值） |
   | username | 你的帳號 |
   | password | 你的密碼 |

5. 按 OK，登入後就是全螢幕的 Firefox 空白分頁。

> 如果連線後沒有出現 xrdp 登入畫面、直接進到桌面，代表遠端桌面連線記住了帳密。這樣也可以正常使用；但要加入別人的 session（第 5 節）時，必須看得到登入畫面，請在連線視窗按「顯示選項」，刪除儲存的認證後再連。（這個情況未實測。）

## 2. 使用 Firefox

- 畫面只有 Firefox，沒有工作列和桌面。Firefox 被關掉後會在 1 秒內自動重新開啟。
- 解析度跟著你的遠端桌面視窗大小。
- **輸入中文**：桌面內建新酷音（注音）輸入法。你電腦上的輸入法請保持英文，在遠端桌面裡**單獨按一下左 `Shift`**（或 `Ctrl+Space`）切換到注音，再按一次切回英文。按住 `Shift` 打大寫字母不會切換。你電腦上的中文輸入法打出的字傳不進遠端桌面。
- **貼上**：在你的電腦複製後，到 Firefox 按 `Ctrl+V`（Mac 用 `Cmd+V`）貼上，中文也可以。
- **下載檔案**：會跳出視窗讓你選儲存位置。檔案存在這個連線專用的暫存目錄，**連線結束後會被刪除**，請在連線期間處理完畢。

## 3. Web 終端機

在 Firefox 網址列輸入：

| 網址 | 內容 |
| --- | --- |
| `http://localhost:2200` | bash 終端機。只有一個帳號時直接以該帳號進入；有多個帳號時先出現 `login:`，輸入自己的帳號密碼 |
| `http://localhost:2210` | 直接 SSH 到 `tkadm.taroko`（22100 埠，以 `myssh` 連線）。只有一個帳號時以該帳號登入；有多個帳號時先問「tkadm.taroko 的帳號:」，輸入你在 tkadm 上的帳號 |

- 每開一個分頁就是一個獨立的終端機，有自己的暫存家目錄，關掉分頁就刪除。
- 終端機只能在遠端桌面裡的 Firefox 開啟，從你自己電腦的瀏覽器連不到。
- 有些組合鍵會先被 Firefox 攔截，例如 `Ctrl+W` 會關掉分頁。在 nano 裡可以改用功能鍵：`F2` 離開、`F3` 存檔、`F1` 說明。
- 滑鼠滾輪可以往回看 10000 行輸出。
- **貼上**請按 `Ctrl+Shift+V` 或 `Shift+Insert`（Mac 上是 `Control+Shift+V`）。`Ctrl+V`（Mac 的 `Cmd+V`）在終端機裡會被當成控制字元，不會貼上。
- 輸入中文的方式和 Firefox 一樣：單獨按一下左 `Shift` 切換注音。

## 4. 多人同時使用

- 每條連線都會拿到**自己獨立的桌面**：不論用不同帳號，還是多人共用同一個帳號，Firefox 分頁、下載、終端機都不會互相看到或影響。
- 同時最多 **4 個**桌面（所有帳號合計）。超過時會看到 `Can't create session for user <帳號> - Max session limit reached`。
- **斷線後無法接回原本的桌面**。重新連線一定會拿到全新的 Firefox，原本的桌面會在斷線 2 分鐘後被回收，裡面的分頁和檔案都會消失。
- 共用同一個帳號的人，在終端機用 `ps` 看得到彼此的程式；不同帳號之間看不到對方的檔案與分享 PIN。

## 5. 分享你的桌面

### 5-1 擁有者：取得編號與 PIN

登入約 2 秒後，畫面中央會跳出「分享這個 session（編號 10）」視窗，內容包含：

- **編號**：例如 `10`，別人加入時要選 `join10`。
- **操作 PIN**（6 位數）：用這組加入的人可以操作你的桌面。
- **唯讀 PIN**（6 位數）：用這組加入的人只能看。

要分享給誰、給哪一組 PIN，由你決定。PIN 每次登入都會重新產生，桌面結束就失效。

- 視窗關掉之後，按 **`Ctrl+Alt+S`** 可以再叫出來。
- **開始分享前，請先關掉這個視窗**，否則加入的人會在你的畫面上看到操作 PIN。

### 5-2 加入者：加入別人的桌面

1. 照第 1 節連到 `192.168.11.64`，出現 xrdp 登入畫面。
2. **Session** 改選 `join<編號>`，例如 `join10`。可以用滑鼠點開選單選，也可以先點一下 Session 欄位再按 `↓` 鍵切換。選好後，表單只剩 **password** 一欄。
3. **password** 填對方給你的 PIN。
4. 按 OK，就會看到對方的畫面。

> 不要在 username 填 `join10\<帳號>` 這類名稱：Session 仍是 `Xorg` 時，系統會把它當成帳號，回覆找不到使用者。

### 5-3 分享時要知道的事

- 擁有者和所有用操作 PIN 加入的人**共用同一組滑鼠鍵盤**，同時操作會互相干擾。
- 加入者的畫面大小固定跟著擁有者，視窗無法放大到全螢幕。需要時在遠端桌面連線的標題列按右鍵，勾選「智慧型調整大小」（Smart sizing），畫面就會跟著視窗縮放。
- 加入者的剪貼簿只支援英數字，中文請由擁有者自己貼上。
- 擁有者斷線後，桌面還會保留 2 分鐘，這段時間內已加入的人仍看得到畫面；桌面被回收時，所有加入者會一起斷線。
- 加入者不佔用第 4 節的 4 個桌面名額，也不需要有帳號，只要有 PIN 就能加入。

## 6. 常見問題

| 看到的訊息或現象 | 原因 | 處理 |
| --- | --- | --- |
| 憑證警告「無法驗證此遠端電腦的身分識別」 | Pod 使用自己產生的憑證 | 按「是」繼續 |
| `User does not exist, or could not be authenticated` | 帳密錯誤；或 Session 不是 `Xorg` 卻填了帳號；或 Session 是 `Xorg` 卻在 username 填了 `join10\...` | 一般登入：Session 選 `Xorg`、填自己的帳號密碼。加入別人：Session 選 `join<編號>`、只填 PIN |
| `VNC password failed` / `Error connecting to user session` | PIN 錯誤，或對方的桌面已經結束 | 向對方確認編號與 PIN（對方按 `Ctrl+Alt+S` 可再看一次）。連續輸錯多次會被暫時封鎖一段時間 |
| `Max session limit reached` | 已經有 4 個桌面在使用 | 等別人登出；剛斷線的桌面要 2 分鐘後才會釋放 |
| 重新連線後，原本開的分頁不見了 | 每次連線都是新的桌面，斷線的桌面會被回收 | 無法接回，請重新開啟 |
| 連線後直接進到桌面，沒有登入畫面 | 遠端桌面連線記住了帳密 | 一般使用沒影響；要加入別人時，刪除儲存的認證後再連 |
| 不小心關掉 Firefox | — | 等 1 秒會自動重新開啟 |

> 本手冊的步驟已於 2026-10-25 在 tk8s 上，以 FreeRDP 經 `192.168.11.64:3389` 模擬 Windows 遠端桌面連線的操作實測：xrdp 登入畫面一般登入、分享視窗與 `Ctrl+Alt+S`、Session 選 `join10` 後以唯讀 PIN 加入只能看、以操作 PIN 加入可以操作、錯誤 PIN 被拒、第 5 個桌面被拒、localhost:2200 終端機。尚未用實體 Windows 電腦實測；「遠端桌面連線記住帳密時直接進入桌面」一項未實測。

> 3.5-share 的多帳號功能已於 2026-10-25 實測：兩個帳號（其中一組密碼含冒號）在 xrdp 登入畫面各自登入、取得獨立桌面，錯誤密碼與名單外帳號被拒，跨帳號以 PIN 加入分享，以及多帳號時 `localhost:2200` 先要求登入。

> 3.6-share 已於 2026-10-27 在 tk8s 實測：以 FreeRDP 及 macOS 的 Windows App 連線，在 Firefox 網址列、`localhost:2200` 與 `localhost:2210` 終端機以新酷音輸入中文，左 `Shift` 與 `Ctrl+Space` 切換中英、按住 `Shift` 打大寫不會切換，終端機以 `Ctrl+Shift+V`、`Shift+Insert` 貼上中文。

> 3.7-share 已於 2026-10-27 在 tk8s 實測：不設定 `SSH_TARGET` 時 `localhost:2210` 直接連到 tkadm 的 22100 埠並執行 `kubectl get nodes`；多帳號（alice、bigred）時以 alice 登入，`localhost:2210` 先詢問帳號，`-oProxyCommand=id` 等不合格式的輸入被拒，輸入 `bigred` 後登入 tkadm。
